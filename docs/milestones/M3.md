# M3 — Animation Library + Retarget

Implementation plan for PRD §10 milestone **M3**. Builds on
[M2.md](M2.md). PRD wins on scope, DESIGN wins on detail, this doc wins on M3
sequencing.

## Goal

Author canonical clips (idle / walk / run / tail_wag / bark_pose) **once on the
canonical rig** and emit them as glTF animation channels. Because every generated
skeleton shares the bone topology, retarget is trivial: clips are procedural joint
**rotations** authored against the actual (proportioned) skeleton, so they fit any
proportions with no remapping.

**Exit (PRD §10):** the tail-wag visibly drives the tail bone (feeds the existing
behavior lane); locomotion loops cleanly.

## Why rotations on joint nodes "just work"

In M1 we proved rest pose is identity (joint local `T(head-parent.head)`, inverse
bind `T(-head)`). Animating a joint's **rotation** rotates its bound vertices
about that joint's head — exactly the tail-wag we hand-verified in M1. So clips =
per-joint quaternion tracks; no IK, no mocap, no retarget math.

## Clips (procedural, deterministic — DESIGN §3)

- **tail_wag** — `tail_01/02/03` rotate about **Y** (up) as a phase-lagged
  sinusoid with amplitude rising toward the tip (whip). The behavior-lane clip.
- **idle** — subtle breathing: small slow sinusoid on spine/neck/head about **Z**.
- **walk** — diagonal gait: thighs swing about **Z** (front-left ↔ hind-right in
  phase, opposite pair anti-phase), shins add knee bend, small root vertical bob.
  Period chosen so it loops seamlessly.
- **run** — walk with larger amplitude + shorter period.
- **bark_pose** — quick head/neck thrust up about **Z** and back (half-sine).

Each clip is one shared time track + per-joint value tracks. Loop-seamless: endpoint
sample equals start.

## Coordinate axes (our frame: +X fwd, +Y up, +Z left)

wag → about Y; leg fore/aft swing & head nod/thrust → about Z; body roll → about X.

## File changes

- `types.py` — add `Channel(bone, path, values)` and `AnimClip(name, times,
  channels)`.
- `animation.py` — **new**: `animate(skel, spec) -> list[AnimClip]` + quaternion
  helpers; one authoring function per clip.
- `spec.py` — parse `animations` (default `[idle, walk, tail_wag, bark_pose]`).
- `assemble.py` — emit `animations` + samplers/accessors (LINEAR), shared time
  accessor per clip; channels target joint nodes by bone index. Skinned path only.
- `cli.py` — call `animate`, pass clips to `write_outputs`.

## Determinism

Clips are analytic (no RNG). Animation buffer is exact f32 bytes; time accessors
carry required min/max. Determinism test extended to include clips in the glTF.
