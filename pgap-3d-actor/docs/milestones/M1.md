# M1 — Canonical Quadruped Rig + Skinning

Implementation plan for PRD §10 milestone **M1**. Builds on
[M0.md](M0.md). PRD wins on scope, DESIGN wins on detail, this doc wins on M1
sequencing.

## Goal

Replace the M0 hardcoded scaffold with a **data-driven canonical quadruped rig**
proportioned from `spec.proportions`/`traits`, derive **distance-to-bone skin
weights**, and export a real **skinned** glTF (joints + weights + inverse-bind
matrices + joint node hierarchy).

**Exit (PRD §10):** an animatable skeletal mesh; weights valid (normalized, ≤4
influences/vertex, no unweighted vertices). Still deterministic.

## In scope / deferred

- **In scope:** canonical bone graph (frozen names), proportioning, skinning,
  skinned glTF, a first `import.json` sidecar, fuller spec parsing.
- **Deferred:** breed part-library + recognizable dog tuning (M2), animation clips
  (M3), UVs/textures (M4), proof-lane integration (M5).

## Canonical rig (frozen bone names — the contract with M3 anims + import.json)

Axial: `root` (pelvis) → `spine_01` → `spine_02` → `neck_01` → `head` → `snout`;
ears `ear_l`/`ear_r` (children of `head`); tail chain `tail_01` → `tail_02` →
`tail_03`. Four legs, 3 bones each (thigh/shin/paw):
`thigh_fl shin_fl paw_fl`, `…_fr`, `…_hl`, `…_hr`. Front legs parent `spine_02`,
hind legs parent `root`. (23 bones.) `tailBone` in the spec = `tail_01`.

## Stage algorithms

1. **Skeleton (`skeleton.py`)** — canonical rig is **data**: per bone
   `(name, parent, rest head, rest tail, radius_head, radius_tail, group)`. The
   builder derives each bone's *attach* point (projection of its head onto the
   parent segment) and *lateral* offset once, then rebuilds world positions in
   topo order so scaling a parent moves its whole subtree. Group factors:
   `bodyLength`→spine, `legLength`→legs, `neck`→neck, `tail`→tail chain,
   `traits.snout`→snout length. Uniform `heightCm` global scale, then a
   ground-clamp (shift so the lowest paw sits at y=0). Pure-analytic,
   deterministic.
2. **Skinning (`skinning.py`)** — point-to-segment distance from every vertex to
   every bone (vectorized N×B). Take the nearest ≤4 bones, weight by inverse
   square distance, normalize. Fills `Mesh.joints` (u16[N,4], bone indices) and
   `Mesh.weights` (f32[N,4]). Zero-weight slots get joint 0. No heat solve in M1.
3. **Skinned glTF (`assemble.py`)** — one node per joint in a hierarchy (local
   translation = `head − parent.head`, so accumulated global = `head`), a `skin`
   with `joints` + `inverseBindMatrices` (= `T(−head)`, so rest is identity),
   mesh primitive gains `JOINTS_0`/`WEIGHTS_0`. Static path (M0) retained when
   `mesh.joints is None`.
4. **`import.json` sidecar** — `targetSkeletonName`, `tailBone`, `archetype`,
   ordered bone-name list (FR3: names match anim lib + sidecar).

## Determinism

- No new RNG draws; rig + skin are analytic. Buffer stays exact f32/u16/u32
  bytes; node translations & IBMs are plain floats in sorted-key JSON.
- Determinism test extended to the skinned glTF SHA.
