# M7 — LLM Front-End + Corpus

Implementation plan for PRD §10 milestone **M7** (final). Builds on M0–M6.

## Goal

Close the loop: a **capability report + spec validation** that fails closed on
unsupported requests (FR7), a deterministic **NL prompt → spec** inference layer
(the interface an LLM targets), and a **golden corpus + variance regression**
suite. **Exit: end-to-end "prompt → playable actor" + regression suite.**

## Parts

### 1. Capabilities + validation (`capabilities.py`) — FR7
- `capability_report()` → the machine-readable contract of what's supported:
  archetypes, known species (which get a part library), trait vocab + allowed
  values, animations per archetype, coat keywords, proportion ranges.
- `validate_spec(data)` → `{ok, errors, warnings, normalized}`. **Fails closed:**
  unsupported archetype → error; unknown trait value → clamp to default +
  warning; animation not available for archetype → dropped + warning; unknown
  species → generic (no parts) + warning; out-of-range proportion → clamped.
  This is the gate an LLM/human front-end calls before generation.

### 2. NL front-end (`nl.py`)
- `prompt_to_spec(prompt, seed)` → spec dict via deterministic keyword inference
  (archetype from dog/rock/person words, traits from "floppy ears"/"long snout",
  coat from color words, proportions from "tall"/"long-bodied"). An LLM can emit
  the spec JSON directly instead; this is the offline/deterministic fallback and
  the thing `validate_spec` guards. Quotes the source — no network in core.

### 3. Golden corpus / variance regression (`tests/test_corpus.py`)
- For dog / biped / prop, generate N seeds; assert every output is valid
  (single-component, within budget, finite, weights normalized for skeletal) —
  "no degenerate/exploded meshes" (PRD §9). Same seed → identical SHA.

### CLI
- `--prompt "<text>"` infer + validate + generate. `--capabilities` prints the
  report. `--seed` overrides.

## Exit checklist

- [ ] `capability_report()` enumerates supported archetypes/traits/anims/coats
- [ ] `validate_spec` fails closed on unsupported archetype; clamps/warns on the
      rest
- [ ] `prompt_to_spec` maps representative prompts to valid specs
- [ ] `--prompt` runs end to end (prompt → glTF)
- [ ] Variance suite: N seeds × {dog, biped, prop} all valid + deterministic
- [ ] All prior tests still pass
