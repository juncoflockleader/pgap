Implementation plan for PRD §10 milestone **M5**. Builds on

## Goal

Slot pgap into the `unreal-mcp-rx` **source-worker role + project-clone proof
lane**: regenerate the golden retriever, hand off the generated source assets,
and pass the lane green (import + material + Blueprint assembly + bark/tail-wag
PIE). **Exit: FR6.**

## The source-handoff contract (from the unreal-mcp-rx repo)

Verified in `src/unreal_mcp_rx/planning/interactive_component.py`. An external
generator hands off **separate role files** + a manifest:

| Role | File | Unreal asset | Key metadata |
|---|---|---|---|
| `dog_mesh` | `SK_<Name>.gltf` | skeletal_mesh | `skeletonPolicy: create_from_fbx` |
| `tail_animation` | `A_<Name>_TailWiggle.gltf` | animation_sequence | `targetSkeleton`, `tailBoneOrSocket: tail_03` |
| (texture) | `T_<Name>_Fur_BaseColor.png` | texture | — |
| (audio) | `S_<Name>_Bark.wav` | audio | **NOT pgap** — lane placeholder |

- Manifest schema: `game.interactive_component_agent_source_manifest.v1`; each
  `files[]` entry carries `requestId, roleId, role, assetType,
  desiredUnrealAssetType, targetPackage, sourceFile, sourceFormat, sha1,
  generator, prompt, licenseNote, replacementCriteria, importCompatibility{…}`.
- glTF preferred over FBX; mesh import auto-creates the skeleton; **bone names
  must match** between mesh and animation (they do — one canonical rig).
- The tail-wag must move bone **`tail_03`** (our wag animates `tail_01/02/03`, tip
  included). Behavior: proximity bark (audio) + proximity tail-wiggle (anim).

## Split of responsibilities

- **pgap (this milestone, bridge-independent):** emit the correctly-named source
  bundle — `SK_…gltf` (mesh+skin+material, no clips), `A_…_TailWiggle.gltf`
  (skeleton + the `tail_wag` clip only), `T_…_BaseColor.png` — plus a manifest
  shaped to the v1 schema with per-file sha1 + importCompatibility.
- **Live lane (needs bridge):** `interactive_component_plan` with the filled
  manifest → import → author `M_<Name>Fur` (vertex-color-aware fur material) →
  assemble `BP_<Name>` → `pie_test_bp` bark + tail-wag →
  `interactive_component_project_clone_proof_history_run`.

## Stage / file changes (pgap side)

- `assemble.py` — add `assemble_anim_gltf(name, skel, clips)`: skeleton joint
  nodes + animation channels, **no mesh/skin** (animation-only glTF).
- `handoff.py` — **new**: `export_source_bundle(spec, out_dir, package_root)`
  writes the role files (SK/A/T names) + `<Name>.source_manifest.json`
  (v1 schema, importCompatibility, sha1s). Tail metadata = `tail_03`.
- `cli.py` — `--handoff` flag (and/or `pgap.handoff` entry) to emit the bundle.
- `fixtures` / spec — `tailBone` aligned to `tail_03` for the motion contract.

## Determinism

Bundle files + manifest are deterministic (sha1s stable). Tests cover bundle
layout, anim-only glTF structure, and manifest schema fields.
