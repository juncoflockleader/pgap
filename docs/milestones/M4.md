# M4 — UV + Texture Synth

Implementation plan for PRD §10 milestone **M4**. Builds on
[M3.md](M3.md). PRD wins on scope, DESIGN wins on detail, this doc wins on M4
sequencing.

## Goal

Give the dog a **golden fur material, not flat color**: UV coordinates, a
procedural golden-fur base-color texture, region tints (darker ears, cream
belly/chest, lighter muzzle/legs), and a PBR material — all embedded in the glTF
so the existing import produces a textured material.

**Exit (PRD §10):** golden fur material, not flat color.

## Approach (procedural-only first; image-gen hook deferred)

DESIGN's atlas exists so an *image-gen* base color can be painted into region
rects. M4 ships the **procedural fallback** (PRD open-Q #3) and composes color the
way glTF already multiplies it:

`baseColor = baseColorTexture (golden fur, sRGB) × COLOR_0 (per-vertex region tint)`

- **UVs** (`uv.py`) — cylindrical unwrap about the body's long axis (+X):
  `u = atan2(z,y)/2π + 0.5`, `v = normalized x`. Valid `[0,1]`, consistent texel
  density, seams acceptable (DESIGN: determinism over perfection). Carries the
  tiling fur texture.
- **Region tint** (`paint.py`) — per-vertex `COLOR_0` set so `texture × color ≈
  target` for each region (target chosen per dominant bone group + belly test):
  golden back, dark ears, cream belly/chest, light muzzle, cream lower-leg/tail
  feathering. `color = clamp(target / golden_base)`.
- **Texture** (`texture.py`) — procedural golden-fur base color: golden palette ×
  multi-octave value noise (seeded RNG → deterministic). Minimal hand-rolled PNG
  encoder (zlib, RGB8). Roughness/metallic as material factors (fur = matte).
- **Palette** (`palette.py`) — golden-retriever palette + keyword detection from
  `material.baseColor` (golden/brown/black/cream), region targets.

## File changes

- `types.py` — add `Mesh.colors`.
- `spec.py` — parse `material` (`baseColor` str, `fur` bool, `roughness`).
- `uv.py`, `paint.py`, `texture.py`, `palette.py` — new.
- `assemble.py` — emit `TEXCOORD_0`/`COLOR_0`, embed PNG (image/texture/sampler),
  PBR `material` (baseColorTexture, metallic 0, roughness ~0.9, doubleSided).
  Write `<Name>_BaseColor.png` artifact; manifest lists it.
- `pipeline.py` — `build_actor` fills uvs + colors; `build_bundle` adds textures +
  clips (single deterministic order for CLI + tests).

## Determinism

Texture noise uses the threaded seeded RNG (first output-affecting RNG use); PNG
is exact bytes (zlib level fixed). Same `(spec, seed)` → identical PNG + glTF.

## Exit checklist

- [ ] UVs valid (`[0,1]`, every vertex), vertex colors present
- [ ] Procedural golden-fur PNG written + embedded; glTF carries a PBR material
- [ ] Import into live UE → textured **golden** dog (ears darker, belly lighter),
      not flat
- [ ] Deterministic SHA across processes; all prior tests still pass
