# M6 — Other Archetypes

Implementation plan for PRD §10 milestone **M6**. Builds on M0–M5. PRD wins on
scope, DESIGN wins on detail, this doc wins on M6 sequencing.

## Goal

Generalize beyond the quadruped: a **static-prop fast path** (no rig) and a
**biped** path (reuse skeleton-first). **Exit: a prop and a simple biped
generated.**

## Archetype routing

`spec.archetype ∈ {prop, quadruped, biped}` drives the pipeline:

- **prop** — geometry only: prop primitives → SDF → marching cubes → static glTF
  (UVs + procedural texture/material). **No skeleton, skin, paint, or animation.**
- **quadruped** — the existing dog path (M1–M4), unchanged.
- **biped** — canonical biped rig → geometry around bones → distance-to-bone skin
  → uv → (biped idle/walk clips). Same skeleton-first machinery as the quadruped.

## Stage / file changes

- `spec.py` — `SUPPORTED_ARCHETYPES = (prop, quadruped, biped)`.
- `skeleton.py` — dispatch `build_skeleton` by archetype; shared `_assemble_bones`
  proportioning helper; add `_BIPED_RIG` (root→spine→neck→head, arms
  upperarm/forearm/hand ×2, legs thigh/shin/foot ×2 — ~17 bones, frozen names).
- `archetypes/prop.py` — **new**: `build(spec, rng)` → prop `Primitive`s
  (seed-jittered **rock** by default, **barrel** variant). No bones.
- `animation.py` — archetype-aware: prop → none; quadruped → existing; biped →
  `idle` (breathe + arm sway) + `walk` (leg/arm counter-swing).
- `palette.py` — add a **stone/grey** coat for props.
- `pipeline.py` — branch by archetype: prop skips skin/paint; biped/quadruped run
  the full path.
- `cli.py` — handle empty skeleton (static prop → no skin/import sidecar).
- `fixtures/` — `prop_rock.json`, `biped_simple.json`.

## Determinism

Prop rock uses the threaded seeded RNG (deterministic). Biped rig is analytic.
Same `(spec, seed)` → byte-identical glTF.

## Exit checklist

- [ ] `prop` spec → static textured glTF (no skeleton), mesh valid
- [ ] `biped` spec → skinned glTF with the biped rig (weights valid) + idle
- [ ] Both import into UE (prop = Static/SkeletalMesh-free, biped = SkeletalMesh)
- [ ] Deterministic; all prior tests still pass
