# M0 — Geometry Kernel & Determinism

Implementation plan for PRD §10 milestone **M0**. Companion to [PRD.md](../../PRD.md)
and [DESIGN.md](../../DESIGN.md). Where this and the PRD/DESIGN disagree, the PRD
wins on scope, DESIGN wins on implementation detail, this doc wins on M0 sequencing.

## Goal

SDF/metaball-around-bones kernel → marching cubes → cleanup → normals → glTF
export, with a deterministic seeding spine.

**Exit:** a smooth quadruped blob that imports into Unreal and clearly beats the
box-dog placeholder; same `(spec, seed)` → byte-identical output.

## In scope / deferred

- **In scope:** the geometry *kernel* and the determinism *spine*. A static
  (unrigged, untextured, unanimated) smooth quadruped mesh exported as glTF.
- **Deferred:** canonical rig + proportion params and skin weights (M1), UVs +
  textures (M4), animations (M3). M0 uses a *minimal hardcoded quadruped bone
  layout* only as scaffolding to drive the SDF — not the frozen canonical rig.

## Decisions

- **Marching cubes:** hand-rolled numpy with the standard 256-case edge/tri
  tables. Keeps the core dependency-light and deterministic (DESIGN default).
  `skimage` is *not* a core dependency in M0.
- **Decimation:** hit the tri budget primarily via voxel grid resolution; weld +
  largest-component + manifold check only. Full quadric decimation deferred.
- **Python 3.9 here:** every module uses `from __future__ import annotations`
  (DESIGN samples use 3.10 `X | None` syntax).

## Stage algorithms

1. **SDF primitives** — tapered-capsule SDF: point-to-segment distance minus a
   head→tail interpolated radius. Body/neck/head/4 legs/tail each a capsule.
   Fully numpy-vectorized over the voxel grid.
2. **Blend** — polynomial smooth-min, fixed `k`, into one organic surface.
3. **Surface extraction** — hand-rolled numpy marching cubes, 256-case tables;
   grid resolution derived from `triBudget`, grid sized to skeleton AABB + margin.
4. **Cleanup (FR4 gate, M0 subset)** — weld duplicate verts, keep largest
   connected component, basic manifold/finite check; reject + reseed on failure.
5. **Normals** — area-weighted per-vertex from face normals, deterministic
   accumulation order.
6. **glTF export** — minimal hand-written `.gltf`, embedded base64 buffer
   (POSITION, NORMAL, indices).

## Determinism spine (PRD §11 / DESIGN §4)

- One `Generator(PCG64(seed))`, passed explicitly; never reseeded mid-pipeline.
- No `set`/`dict` ordering in anything affecting output; sort first.
- Fixed float formatting + array dtypes in the glTF buffer.
- `test_determinism.py` re-runs the fixture twice, asserts identical output SHA —
  written alongside the first geometry code (CLAUDE.md requirement).

## Exit checklist

- [ ] `python -m pgap.cli --spec fixtures/quadruped_m0.json` emits `<Name>.gltf`
- [ ] Mesh is smooth, single-component, manifold-ish, within tri budget
- [ ] Determinism: same `(spec, seed)` → identical SHA across two runs
- [ ] glTF structurally valid (UE import is the real acceptance; verified locally
